# Gamla Stan Pizzeria - Officiell Webbplats

En modern, responsiv webbplats för Gamla Stan Pizzeria byggd med Vue 3, Vite och Bootstrap 5.

## 🍕 Om Projektet

Denna webbplats representerar Gamla Stan Pizzeria, en traditionell svensk pizzeria med pub-atmosfär belägen i hjärtat av Stockholm sedan 1985. Webbplatsen är helt på svenska och designad för att spegla den mysiga, varma atmosfären på pizzerian.

## 🎨 Design & Funktioner

### Designtema
- **Färgschema**: Varma bruna toner, djupa röda färger, kräm/beige
- **Stil**: Rustik, mysig, välkomnande pub-atmosfär
- **Typografi**: Tydlig, familjevänlig design

### Huvudfunktioner
- ✅ Fullständigt responsiv design
- ✅ Interaktiv navigation med smooth scrolling
- ✅ Dynamiska öppettider med realtidsstatus
- ✅ Filtrerbar meny med pizzakategorier
- ✅ SEO-optimerad för svenska sökord
- ✅ Tillgänglighetsanpassad (WCAG 2.1 AA)
- ✅ Cross-browser kompatibilitet

### Innehållssektioner
1. **Header** - Logotyp, navigation, telefonnummer
2. **Hero** - Välkomstmeddelande, öppettider, call-to-action
3. **Meny** - Kategoriserad pizzameny med priser i SEK
4. **Om Oss** - Företagshistoria, värderingar, team
5. **Kontakt** - Kontaktinfo, öppettider, kartplats
6. **Footer** - Komplett information, nyhetsbrev, sociala medier

## 🛠 Teknisk Stack

- **Framework**: Vue 3 med Composition API
- **Build Tool**: Vite
- **Styling**: Bootstrap 5
- **Icons**: Bootstrap Icons
- **Språk**: TypeScript
- **Deployment**: Statiska filer (ingen backend krävs)

## 📱 Responsiv Design

Webbplatsen är optimerad för alla enheter:
- Desktop (1200px+)
- Tablet (768px - 1199px)
- Mobile (< 768px)

## 🚀 Installation & Development

### Förutsättningar
- Node.js (v16 eller senare)
- npm eller yarn

### Setup
```bash
# Installera dependencies
npm install

# Starta development server
npm run dev

# Bygg för production
npm run build

# Preview production build
npm run preview
```

### Development URLs
- **Local**: http://localhost:5173/
- **Network**: Använd `--host` flagga för nätverksåtkomst
